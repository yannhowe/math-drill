# Scheduler

The deterministic scheduler chooses today’s highest-value item using an explainable mixture: weak/current material, learning edge, due review, fluent maintenance and bounded probes. Default weights (40/20/15/15/10) are versioned configuration rather than fixed educational truth. It prevents a category with no eligible work from blocking a session.

Successful review intervals begin same day, one day, three days, one week and then lengthen; unsuccessful/assisted attempts shorten interval. Each selection records a reason such as “due for review”, “recent accuracy below target”, or “successor probe after consistent fluent evidence”.
